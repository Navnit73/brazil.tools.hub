## Ferramentas úteis, direto no navegador

O Brasil Tools Hub reúne ferramentas gratuitas para tarefas comuns do dia a dia: redimensionar uma foto para um formulário, juntar PDFs para enviar um documento, calcular uma porcentagem ou gerar um QR Code Pix para receber um pagamento.

Sempre que possível, os arquivos são processados no seu próprio dispositivo, sem envio para servidores.

## Perguntas frequentes

### As ferramentas são gratuitas?

Sim. Todas as ferramentas podem ser usadas gratuitamente e sem cadastro.

### Preciso instalar algum programa?

Não. Tudo funciona no navegador, no computador ou no celular.
