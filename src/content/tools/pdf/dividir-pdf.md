# Dividir PDF online grátis

Use nossa ferramenta para **dividir PDF** em vários arquivos menores: uma página por arquivo, a cada N páginas ou pelos intervalos que você escolher. É a forma mais rápida de **separar PDF** em partes para enviar só o que importa, sem cadastro e sem instalar nada.

O arquivo é processado no seu navegador e não é enviado para nenhum servidor.

## Como dividir um PDF

1. Selecione o arquivo PDF ou arraste-o para a área indicada.
2. Escolha o modo de divisão: **Uma página por arquivo**, **A cada N páginas** ou **Por intervalos**.
3. Confira a prévia: cada página mostra uma etiqueta colorida **Arquivo N** indicando em qual arquivo ela vai ficar.
4. Toque em **Dividir PDF** e baixe os arquivos um por um ou todos juntos em um .zip.

## Modos de divisão

### Uma página por arquivo

Cada página vira um PDF separado. Um documento de 10 páginas gera 10 arquivos. É o jeito mais simples de **separar páginas do PDF** quando você precisa de cada uma isolada.

### A cada N páginas

Informe quantas páginas cada parte deve ter. Com N = 5, um PDF de 20 páginas vira quatro arquivos de 5 páginas. Útil para **dividir PDF em partes** iguais, como capítulos ou lotes de documentos digitalizados.

### Por intervalos

Digite exatamente quais páginas vão em cada arquivo, separando os intervalos por vírgula:

- `1-3, 4-6` gera dois arquivos: um com as páginas 1 a 3 e outro com as páginas 4 a 6.
- `8-` significa da página 8 até o final do documento.

É o modo ideal para **cortar PDF** em pedaços de tamanhos diferentes.

## Prévia com etiquetas coloridas

Antes de dividir, a grade de miniaturas mostra uma etiqueta **Arquivo 1**, **Arquivo 2** e assim por diante em cada página, cada uma com uma cor. Assim você confere se a divisão está certa antes de baixar.

## Dividir, extrair ou remover?

- **Dividir PDF:** o documento inteiro é repartido em vários arquivos.
- **[Extrair páginas](/ferramentas/pdf/extrair-paginas-pdf):** você escolhe algumas páginas e gera um novo PDF só com elas.
- **[Remover páginas](/ferramentas/pdf/remover-paginas-pdf):** você exclui as páginas que não quer e mantém o resto em um único arquivo.

Se depois precisar unir partes de novo, use o [Juntar PDF](/ferramentas/pdf/juntar-pdf).

## Perguntas frequentes

### Como dividir um PDF em vários arquivos?

Selecione o PDF, escolha **Uma página por arquivo**, **A cada N páginas** ou **Por intervalos**, confira a prévia e toque em **Dividir PDF**. Depois baixe os arquivos.

### Como separar só algumas páginas do PDF?

Use **Por intervalos** e digite as páginas, como `1-3, 4-6`. Se quiser um único arquivo com páginas escolhidas, o [Extrair páginas do PDF](/ferramentas/pdf/extrair-paginas-pdf) é mais direto.

### O que significa "8-" no intervalo?

Significa da página 8 até a última página do documento.

### Como baixar todos os arquivos de uma vez?

Depois de dividir, você pode baixar cada arquivo separadamente ou todos juntos em um único .zip.

### Como sei em qual arquivo cada página vai ficar?

Na prévia, cada página mostra uma etiqueta colorida **Arquivo N** com o número do arquivo de destino.

### Dividir PDF é grátis?

Sim. Você pode usar quantas vezes quiser, sem cadastro.

### Meu PDF é enviado para algum servidor?

Não. A divisão acontece no seu navegador e o arquivo não sai do seu dispositivo.
