# Girar PDF online grátis

Use nossa ferramenta para **girar PDF** e salvar o documento já na posição certa. Gire todas as páginas de uma vez ou só as que estão de lado ou de cabeça para baixo, vendo a prévia antes de baixar. Grátis, sem cadastro, e o arquivo não sai do seu dispositivo.

## Como girar um PDF

1. Selecione o arquivo PDF ou arraste-o para a área indicada.
2. Para **girar todas as páginas**, use os botões de girar para a esquerda ou para a direita.
3. Para girar só algumas, toque na página (cada toque gira 90° para a direita) ou use os botões de esquerda e direita de cada miniatura.
4. Confira a prévia e toque em **Salvar PDF girado**.

## Girar todas as páginas ou só algumas

### Todas de uma vez

Quando o documento inteiro foi digitalizado deitado, use **Girar todas as páginas** para a esquerda ou para a direita. Todas as páginas giram juntas.

### Página por página

É comum só uma ou outra página estar torta: uma tabela em paisagem no meio de um relatório, ou uma folha que entrou invertida no scanner. Para **girar páginas do PDF** individualmente:

- **Toque na página:** gira 90° para a direita a cada toque.
- **Botões de cada miniatura:** giram aquela página para a esquerda ou para a direita.

A prévia mostra a rotação na hora, então você vê o resultado antes de salvar.

### Desfazer tudo

Errou ou quer começar de novo? Toque em **Desfazer tudo** e todas as páginas voltam à posição original.

## Girar PDF e salvar

Muitos leitores de PDF deixam **rotacionar o PDF** só na tela: ao fechar, o arquivo volta como era. Aqui a rotação é gravada no próprio arquivo. Você baixa um PDF que já abre na posição certa em qualquer computador ou celular.

O resto do documento é mantido intacto: o texto, as imagens e as demais páginas não são alterados.

## Perguntas frequentes

### Como girar um PDF e salvar?

Selecione o PDF, gire todas as páginas ou só as que precisam, confira a prévia e toque em **Salvar PDF girado**. O arquivo baixado já abre na posição certa.

### Como girar só uma página do PDF?

Toque na página para girá-la 90° para a direita ou use os botões de esquerda e direita da miniatura.

### Como virar um PDF de cabeça para baixo?

Toque duas vezes na página (2 x 90° = 180°) ou gire todas as páginas duas vezes para o mesmo lado.

### Posso desfazer a rotação?

Sim. Toque em **Desfazer tudo** para voltar todas as páginas à posição original antes de salvar.

### A rotação fica salva no arquivo?

Sim. A rotação é gravada no PDF e o arquivo abre girado em qualquer leitor.

### Girar o PDF altera o conteúdo?

Não. Só a orientação das páginas muda. O texto, as imagens e as demais páginas continuam iguais.

### Meu PDF é enviado para algum servidor?

Não. A rotação acontece no seu navegador e o arquivo não sai do seu dispositivo.
