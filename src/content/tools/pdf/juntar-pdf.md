# Juntar PDF online grátis

Use nossa ferramenta para **juntar PDF** em poucos segundos: selecione os arquivos, defina a ordem e baixe um único documento. Dá para **unir PDF**, **mesclar PDF** ou **combinar PDF** de contratos, comprovantes, boletos e trabalhos escolares sem instalar nada e sem cadastro.

Tudo acontece no seu navegador. Os arquivos não são enviados para nenhum servidor.

## Como juntar arquivos PDF

1. Selecione os PDFs que quer unir (até 50 arquivos, com até 100 MB cada) ou arraste-os para a área indicada.
2. Confira a prévia da primeira página e o número de páginas de cada arquivo.
3. Arraste os arquivos ou use as setas para cima e para baixo para definir a ordem. Se preferir, toque em **Ordenar por nome**.
4. Toque em **Juntar PDFs** e baixe o documento final.

O arquivo unido recebe o nome do primeiro PDF da lista seguido de "-unido". Por exemplo, se o primeiro arquivo é `contrato.pdf`, o resultado será `contrato-unido.pdf`.

## Definir a ordem dos arquivos

A ordem da lista é a ordem em que as páginas aparecem no PDF final. Você tem três formas de organizar:

- **Arrastar e soltar:** segure um arquivo e solte na posição desejada.
- **Setas para cima e para baixo:** mais prático no celular ou para ajustes finos.
- **Ordenar por nome:** útil quando os arquivos já estão numerados, como `parte-1.pdf`, `parte-2.pdf` e `parte-3.pdf`.

A miniatura da primeira página ajuda a reconhecer cada documento antes de juntar.

## Juntar PDF para enviar a órgãos públicos e empresas

Muitos sites pedem **um único arquivo PDF** com todos os documentos: RG, CPF, comprovante de residência, diplomas. Com esta ferramenta você **junta arquivos PDF** na ordem pedida e envia tudo de uma vez.

Se o arquivo final ficar acima do limite do site, passe o resultado pelo [Comprimir PDF](/ferramentas/pdf/comprimir-pdf) para reduzir o tamanho.

## E se eu precisar mexer nas páginas?

Esta ferramenta une arquivos inteiros. Para trabalhar página por página:

- Para reordenar, girar ou excluir páginas depois de juntar, use o [Organizar PDF](/ferramentas/pdf/organizar-pdf).
- Para separar o documento de novo em partes, use o [Dividir PDF](/ferramentas/pdf/dividir-pdf).
- Para juntar fotos em vez de PDFs, use o [JPG para PDF](/ferramentas/pdf/jpg-para-pdf).

## PDF com senha

PDFs protegidos por senha não podem ser unidos diretamente. Primeiro remova a senha com o [Desbloquear PDF](/ferramentas/pdf/desbloquear-pdf), informando a senha que você já conhece, e depois junte normalmente.

## Perguntas frequentes

### Como juntar PDF online?

Selecione os arquivos, coloque-os na ordem desejada arrastando ou usando as setas e toque em **Juntar PDFs**. O documento unido fica pronto para baixar na hora.

### Quantos arquivos posso juntar de uma vez?

Até 50 arquivos PDF, com até 100 MB cada um.

### Como mudar a ordem dos PDFs?

Arraste cada arquivo para a posição desejada ou use as setas para cima e para baixo. O botão **Ordenar por nome** coloca a lista em ordem alfabética.

### Qual o nome do arquivo final?

O PDF unido recebe o nome do primeiro arquivo da lista com "-unido" no final, como `contrato-unido.pdf`.

### Posso juntar PDF com senha?

Não diretamente. Remova a senha antes com o [Desbloquear PDF](/ferramentas/pdf/desbloquear-pdf) e depois junte os arquivos.

### Juntar PDF é grátis?

Sim. Você pode usar quantas vezes quiser, sem cadastro e sem instalar nada.

### Consigo juntar PDF pelo celular?

Sim. A ferramenta funciona no navegador do celular, do tablet e do computador.

### Meus arquivos são enviados para algum servidor?

Não. A junção acontece no seu navegador e os PDFs não saem do seu dispositivo.
