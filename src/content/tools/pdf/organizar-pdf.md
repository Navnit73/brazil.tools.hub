# Organizar Páginas de PDF Online Grátis

Use nossa ferramenta para **organizar PDF** página por página: arraste as miniaturas para **mudar a ordem das páginas**, gire, exclua e insira páginas de outros PDFs ou em branco. Tudo em uma só tela, com a prévia do documento final. Grátis, sem cadastro, e o arquivo não sai do seu dispositivo.

## Como organizar um PDF

1. Selecione o arquivo PDF ou arraste-o para a área indicada.
2. Arraste as miniaturas para a nova posição ou use as setas.
3. Gire ou exclua as páginas que precisar.
4. Se quiser, insira páginas de outro PDF ou uma página em branco.
5. Toque em **Salvar PDF** e baixe o documento organizado.

## O que dá para fazer

### Reordenar páginas

Segure uma miniatura e solte onde quiser, ou use as setas para mover a página uma posição de cada vez. É a forma mais simples de **reordenar páginas do PDF** quando o scanner embaralhou a ordem ou quando você quer mudar a sequência de um documento.

### Inverter ordem

O botão **Inverter ordem** coloca a última página em primeiro e assim por diante. Útil para documentos digitalizados de trás para frente.

### Girar e excluir

Cada miniatura tem botões para girar a página e para excluí-la. Assim você corrige páginas de lado e tira páginas em branco sem trocar de ferramenta.

### Inserir páginas de outros PDFs

Toque em **Adicionar páginas de outro PDF** para trazer páginas de outros arquivos. Quando há mais de um arquivo de origem, cada página ganha uma etiqueta com a letra do arquivo e o número da página, como **A1** ou **B3**, para você saber de onde ela veio.

### Página em branco

Toque em **Página em branco** para inserir uma folha A4 vazia, por exemplo para separar seções ou deixar espaço para anotações na impressão.

### Desfazer tudo

Toque em **Desfazer tudo** para voltar ao documento original e recomeçar.

## Organizar, girar ou juntar?

- Se você só precisa corrigir a orientação, o [Girar PDF](/ferramentas/pdf/girar-pdf) é mais direto.
- Para apenas tirar páginas, use o [Remover páginas do PDF](/ferramentas/pdf/remover-paginas-pdf).
- Para inserir páginas em uma posição específica, veja o [Adicionar páginas ao PDF](/ferramentas/pdf/adicionar-paginas-pdf).
- Para unir arquivos inteiros, use o [Juntar PDF](/ferramentas/pdf/juntar-pdf).

## Perguntas frequentes

### Como mudar a ordem das páginas de um PDF?

Selecione o PDF, arraste as miniaturas para a nova posição ou use as setas e toque em **Salvar PDF**.

### Como inverter a ordem das páginas?

Toque em **Inverter ordem**. A última página passa a ser a primeira.

### Posso girar e excluir páginas na mesma ferramenta?

Sim. Cada miniatura tem botões para girar e para excluir a página.

### Como colocar páginas de outro PDF no meu documento?

Toque em **Adicionar páginas de outro PDF**, escolha o arquivo e arraste as novas páginas para a posição desejada.

### O que significam as etiquetas A1, B3?

Quando você usa mais de um PDF, a letra indica o arquivo de origem e o número indica a página dentro dele.

### Dá para inserir uma página em branco?

Sim. Toque em **Página em branco** para adicionar uma folha A4 vazia.

### Posso desfazer as mudanças?

Sim. **Desfazer tudo** volta o documento ao estado original antes de salvar.

### Meu PDF é enviado para algum servidor?

Não. A organização acontece no seu navegador e o arquivo não sai do seu dispositivo.
