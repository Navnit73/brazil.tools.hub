# Converter PDF para JPG Online Grátis

Use nossa ferramenta para **converter PDF para JPG**: cada página do documento vira uma imagem que você pode enviar pelo WhatsApp, postar ou inserir em outro arquivo. Escolha a resolução, as páginas e baixe. É grátis, sem cadastro, e o PDF não sai do seu dispositivo.

## Como transformar PDF em JPG

1. Selecione o arquivo PDF ou arraste-o para a área indicada.
2. Escolha o formato (**JPG** ou **PNG**) e a resolução: **Baixa (72 DPI)**, **Média (150 DPI)** ou **Alta (300 DPI)**.
3. Ajuste a qualidade do JPG, se quiser (entre 40% e 100%; o padrão é 85%).
4. Converta todas as páginas ou escolha só algumas.
5. Toque em **Converter para JPG** e baixe cada imagem separadamente ou todas juntas em um .zip.

## Qual resolução escolher

| Resolução        | Quando usar                                          |
| ---------------- | ---------------------------------------------------- |
| Baixa (72 DPI)   | Ver na tela, enviar rápido, arquivos bem leves       |
| Média (150 DPI)  | Uso geral: WhatsApp, e-mail, redes sociais           |
| Alta (300 DPI)   | Impressão ou quando precisa ler detalhes pequenos    |

Quanto maior a resolução, mais nítida a imagem e maior o arquivo.

## Qualidade do JPG

O controle de qualidade vai de 40% a 100%, com 85% como padrão. Valores mais altos deixam a imagem mais fiel e o arquivo mais pesado. Para enviar por mensagem, 85% costuma ser suficiente.

## Converter só algumas páginas

Não precisa transformar o PDF inteiro. Você pode:

- **Tocar nas miniaturas** das páginas que quer converter.
- **Digitar intervalos**, como `1-3, 5`.

Assim você tira **foto do PDF** só da página que importa, como um comprovante ou uma página de contrato.

## PDF com senha

Se o PDF for protegido, a ferramenta pede a senha para abrir o arquivo. Depois é só converter normalmente.

## JPG ou PNG?

O JPG gera arquivos mais leves e é ideal para compartilhar. Se você precisa de texto bem nítido ou de uma imagem sem perda de qualidade, use o [PDF para PNG](/ferramentas/pdf/pdf-para-png). Para comparar os dois formatos, veja o [Converter PDF em imagem](/ferramentas/pdf/converter-pdf-em-imagem). E para fazer o caminho inverso, use o [JPG para PDF](/ferramentas/pdf/jpg-para-pdf).

## Perguntas frequentes

### Como converter PDF para JPG?

Selecione o PDF, escolha a resolução e as páginas e toque em **Converter para JPG**. Cada página vira uma imagem JPG que você baixa separadamente ou em um .zip.

### Cada página vira uma imagem separada?

Sim. Um PDF de 5 páginas gera 5 imagens JPG.

### Qual a melhor resolução para converter PDF em JPG?

**Média (150 DPI)** atende a maioria dos usos. Use **Alta (300 DPI)** para impressão ou para ler detalhes pequenos e **Baixa (72 DPI)** para arquivos bem leves.

### Posso converter só uma página do PDF?

Sim. Toque nas miniaturas das páginas desejadas ou digite os intervalos, como `2` ou `1-3, 5`.

### Como baixar todas as imagens de uma vez?

Depois da conversão, baixe todas juntas em um arquivo .zip ou cada uma separadamente.

### Funciona com PDF protegido por senha?

Sim, se você souber a senha. A ferramenta pede a senha para abrir o arquivo.

### PDF para JPEG é a mesma coisa?

Sim. JPG e JPEG são o mesmo formato de imagem, só muda a extensão do nome.

### Meu PDF é enviado para algum servidor?

Não. A conversão acontece no seu navegador e o arquivo não sai do seu dispositivo.
