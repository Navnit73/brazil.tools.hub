# Converter PDF para PNG online grátis

Use nossa ferramenta para **converter PDF para PNG**: cada página do documento vira uma imagem PNG nítida, **sem perda de qualidade**. É a melhor escolha quando o texto precisa ficar bem legível, como em prints de documentos, materiais para impressão ou imagens que você ainda vai editar. Grátis, sem cadastro, e o PDF não sai do seu dispositivo.

## Como transformar PDF em PNG

1. Selecione o arquivo PDF ou arraste-o para a área indicada.
2. Confira se o formato **PNG** está selecionado (já vem como padrão).
3. Escolha a resolução: **Baixa (72 DPI)**, **Média (150 DPI)** ou **Alta (300 DPI)**.
4. Converta todas as páginas ou escolha só algumas, tocando nas miniaturas ou digitando intervalos como `1-3, 5`.
5. Toque em **Converter para PNG** e baixe cada imagem separadamente ou todas juntas em um .zip.

## Por que escolher PNG

O PNG é um formato **sem perda**: a imagem guarda exatamente o que foi desenhado na página. Na prática:

- **Texto nítido:** letras pequenas, tabelas e linhas finas ficam sem borrões.
- **Bom para impressão e edição:** você pode abrir a imagem em um editor sem acumular perda de qualidade.
- **Arquivos maiores:** a contrapartida é que um PNG costuma pesar mais que um JPG da mesma página.

Se o objetivo é só enviar pelo WhatsApp ou e-mail e o tamanho do arquivo importa mais, o [PDF para JPG](/ferramentas/pdf/pdf-para-jpg) gera imagens mais leves.

## Qual resolução escolher

| Resolução       | Quando usar                                        |
| --------------- | -------------------------------------------------- |
| Baixa (72 DPI)  | Ver na tela, imagens leves                         |
| Média (150 DPI) | Uso geral, apresentações, documentos               |
| Alta (300 DPI)  | Impressão e leitura de detalhes pequenos           |

Quanto maior a resolução, mais nítida a imagem e maior o arquivo, o que pesa ainda mais no PNG.

## Perguntas frequentes

### Como converter PDF para PNG?

Selecione o PDF, mantenha o formato PNG, escolha a resolução e as páginas e toque em **Converter para PNG**. Cada página vira uma imagem.

### PDF para PNG perde qualidade?

Não. O PNG é um formato sem perda, então a imagem reproduz a página fielmente na resolução escolhida.

### Qual a diferença entre PNG e JPG?

O PNG não perde qualidade e mantém o texto bem nítido, mas gera arquivos maiores. O JPG é mais leve e ideal para compartilhar.

### Qual resolução usar para imprimir?

Use **Alta (300 DPI)**. Para ver na tela, **Média (150 DPI)** costuma ser suficiente.

### Posso converter só algumas páginas?

Sim. Toque nas miniaturas das páginas desejadas ou digite intervalos como `1-3, 5`.

### Como baixar todas as imagens PNG de uma vez?

Depois da conversão, baixe todas juntas em um .zip ou cada uma separadamente.

### Funciona com PDF protegido por senha?

Sim, se você souber a senha. A ferramenta pede a senha para abrir o arquivo.

### Meu PDF é enviado para algum servidor?

Não. A conversão acontece no seu navegador e o arquivo não sai do seu dispositivo.
